# Fixtures

Fictional orders and payout lines for a made-up store selling on Shopify, Amazon and Etsy, as of 2026-11-16.
Planted: an order never paid out (#1002), an Amazon order paid 2.00 short, an Amazon order never settled,
an order paid in two payouts (#1006), a refund not yet deducted (#1005), an Etsy fee above the 9.5% in
settings.json, a payout line for an order not in the file (#9999) and a reserve held with no order.
