# Fixtures

Fictional fee lines for a made-up seller on Amazon, Etsy and eBay, and a fictional fee schedule (not any
marketplace's real fees). Planted: an Amazon referral charged at 20% on a home item (1.50 over), an FBA fee
0.88 above the fixed amount, an Etsy transaction fee at 8% (0.30 over), a fee type not in the schedule, an eBay
percent fee with no sale amount, and effective-rate moves for Amazon referral (Sep to Oct) and Etsy transaction (Oct to Nov).
