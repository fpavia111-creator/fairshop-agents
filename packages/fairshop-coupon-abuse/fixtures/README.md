# Fixtures

Fictional orders, codes and shoppers (`canaries.json` lists e-mails and addresses that may never reach a tool
result). Planted: a new-customer code used by a returning shopper, the same address under a second e-mail, an
order under the minimum, a single-use code used twice, a limited code used a fourth time, a code used after it
ended, a staff code used outside staff, and a code that is not in the code list.
